# Supplementary upstream license sources

Package-specific copyright/author metadata is retained in the generated
`licenses/<package>/ATTRIBUTION.txt` and original `.nuspec`. Package-supplied
runtime/native notices are copied without alteration. Declared MIT/Apache
terms accompany packages whose NuGet archives omit a separate license file.

- Avalonia: `AvaloniaUI/Avalonia`, commit `2d79ba55fae1b1e71c69f93a668080c9029e6a31`, `licence.md`.
- Ical.Net: `ical-org/ical.net`, commit `1344396c18dfe7349584709990f431931bc0b6be`, `license.md`.
- Apache terms: `nodatime/nodatime`, commit `9c72945729dfa4f9626cd8488f70366c59ed9e94`, `LICENSE.txt`.
- Inter font OFL: `rsms/inter`, tag `v4.1`, `LICENSE.txt` (font license remains separate from the wrapper assembly's MIT license).
- NSIS: official `nsis-3.13.zip`, `COPYING`; the installer selects the zlib module.

These text copies introduce no executable dependencies or runtime network calls.
Review this inventory when upgrading dependencies or preparing external distribution.
